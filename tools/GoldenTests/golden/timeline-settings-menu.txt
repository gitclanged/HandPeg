# The Timeline Settings menu: its groups and items from one table, each kept in a real setting; the five new settings' defaults.
[Lanes & Overlays]
   Show Effect Sub-Lanes on Expanded Tracks  -> AppSettings.ShowTimelineEffectLanes (True in a new install)
   Show Built-In Mask & Edge Lanes on Cutouts  -> AppSettings.ShowBuiltInMaskEffectLanes (False in a new install)
   Show Keyframe Diamonds on Clips  -> AppSettings.ShowClipKeyframes (True in a new install)
   Show Clip Filmstrip Thumbnails  -> AppSettings.ShowClipFilmstrips (True in a new install)
   Show Audio Waveforms  -> AppSettings.ShowClipWaveforms (True in a new install)
   Show Audio Beat Grid  -> AppSettings.ShowBeatGrid (True in a new install)
   Show I-Frame Lines  -> AppSettings.ShowIFrames (True in a new install)
   Gain and Fade Lines  -> AppSettings.ShowClipGainLines (True in a new install)
[Snapping & Playback]
   Enable Timeline Snapping  (key: view.toggleSnap, by default Caps)  -> AppSettings.SnapClips (True in a new install)
   Snap to Audio Beats  -> AppSettings.SnapToBeats (True in a new install)
   Snap Cuts to I-Frames  -> the project's or the session's, not kept in the settings
   Follow Playhead During Playback  -> AppSettings.TimelineFollowsPlayhead (True in a new install)
[Bars & Sizing]
   Show Creator Hotbar  -> AppSettings.ShowCreatorHotbar (True in a new install)
   Show Sequence Overview Scrubber  -> AppSettings.ShowMasterTimeline (True in a new install)
   Track Height  -> AppSettings.LayerHeight (25 in a new install)
[Editing]
   Ripple All Tracks  -> AppSettings.RippleAllTracks (True in a new install)
   Dropped Clips Join Track  -> AppSettings.DroppedClipsJoinTrack (False in a new install)
   Show Linked Audio  -> the project's or the session's, not kept in the settings
