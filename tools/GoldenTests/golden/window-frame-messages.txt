# The frame's messages (5.3): what the hook of a window that draws its own frame (MainWindow.FrameHook: the main window's,
# through TitleBarHook, and the Settings screen's) does with each, and what of them goes on to Windows.
## What the hook decides (MainWindow.FrameDecision), by the window's state
message                   restored              maximized             maximized, strip      minimized
WM_NCACTIVATE, wParam 0   ActivateNoPaint       ActivateNoPaint       ActivateNoPaint       ActivateNoPaint
WM_NCACTIVATE, wParam 1   ActivateNoPaint       ActivateNoPaint       ActivateNoPaint       ActivateNoPaint
WM_SETTEXT                DefaultHidden         DefaultHidden         DefaultHidden         DefaultHidden
WM_SETICON                DefaultHidden         DefaultHidden         DefaultHidden         DefaultHidden
WM_NCCALCSIZE, wParam 0   PassOn                PassOn                PassOn                PassOn
WM_NCCALCSIZE, wParam 1   PassOn                PassOn                PassOn                PassOn
WM_GETMINMAXINFO          PassOn                PassOn                PassOn                PassOn
WM_WINDOWPOSCHANGING      KeepShortThenPassOn   KeepShortThenPassOn   KeepShortThenPassOn   KeepShortThenPassOn
WM_NCPAINT                PassOn                PassOn                PaintStrip            PassOn
WM_NCUAHDRAWCAPTION       Swallow               Swallow               Swallow               Swallow
WM_NCUAHDRAWFRAME         Swallow               Swallow               Swallow               Swallow
WM_NCHITTEST              HitTest               HitTest               HitTest               HitTest
WM_NCMOUSEMOVE            PassOn                PassOn                PassOn                PassOn
WM_NCMOUSELEAVE           PassOn                PassOn                PassOn                PassOn
ok: WM_NCACTIVATE goes to DefWindowProc with lParam -1 in every state, its answer returned (swallowed, answering 0, it would refuse to let the window go inactive)
ok: WM_SETTEXT and WM_SETICON go to DefWindowProc with WS_VISIBLE cleared around them, in every state
ok: WM_NCCALCSIZE is never answered nor changed by HandPeg's hook, in any state (WindowChrome's answers it: the client area is the whole window, so there is never frame outside it)
ok: WM_WINDOWPOSCHANGING: the maximized place is kept short of a taskbar that hides itself, then passed on; WM_GETMINMAXINFO is Windows' own (it reads those numbers for whichever monitor the window maximizes on)
ok: WM_NCPAINT is answered only maximized with frame outside the client area (painted first); otherwise it goes on to Windows, minimized too (answered there, the desktop stops drawing the frame for good)
ok: WM_NCUAHDRAWCAPTION and WM_NCUAHDRAWFRAME (the classic caption's and frame's own) are swallowed in every state
